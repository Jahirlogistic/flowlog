# Evaluación integrada · Clase 1

La evaluación está ubicada en:

`recursos/logistica/procesos-de-aduanas/clase-1/evaluacion/index.html`

El catálogo del portal contiene el enlace relativo a esta ruta. El otro recurso de la asignatura apunta a la compilación oficial del Decreto 1165 de 2019 publicada por la DIAN.

**Prueba obligatoria antes de uso:** completar una evaluación de prueba y confirmar manualmente que se creó una fila en `REGISTRO_EVALUACIONES`. La interfaz utiliza `fetch` con `mode: no-cors`; por diseño no puede confirmar la respuesta del servidor ni garantizar por sí sola el registro.
